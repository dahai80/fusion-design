# 变更说明 v0.1.7（补丁 — 生产验收差距补齐）

## 背景

对 15 项核心特性做生产发布验收后，发现 P0/P1/P2 共 9 项差距。本补丁按优先级补齐。

## P0 — 数据正确性缺陷（发布前必修）

- `fd-canvas-core`：`PenDocumentDiff`/`DiffEntry` 增加 `page_id: Option<String>`（serde `default`，向后兼容）。
- `diff`：新增 `all_nodes_by_page`，Added 条目记录节点所属页面 ID。
- `apply_patch`：Added 分支按 `page_id` 插入正确页面，不再恒定落入 `pages.first()`（修复多页文档节点错位）；目标页缺失时回退首页并 WARN；Modified 节点未找到时 WARN 而非静默。
- `apply_field_change`：补齐 `kind`/`style`/`children` 三类字段（serde 整体反序列化替换），不再静默丢弃。
- 回归测试：`apply_patch_added_node_keeps_page`、`apply_patch_style_kind_children`。

## P1 — 能力未达宣传

- **图生 UI 真传图**（`fd-ai-adapter`）：`ImageToUiSkill`、`DesignSkills::image_to_ui(_async)` 改为读取草图 base64 经 `chat_with_image` 发送真实多模态请求；读取失败回退文字描述并 WARN。新增 `chat_with_image_sync`（BLOCKING_RT 封装）、`SkillContext::chat_with_image(_async)`。
- **CLI 暴露全部 Skill**（`fd-cli`）：新增 `image-to-ui` / `multi-variants` / `spec-doc` / `page-flow` 四个子命令，覆盖 SpecDocSkill(#14)、PageFlowSkill(#15)、MultiVariants、image-to-ui。
- **版本管理集成**（`fd-canvas-core`）：`VersionedDocument` 内嵌 `UndoRedoStack`，`save_version` 自动入栈，新增 `checkpoint`/`can_undo`/`can_redo`/`undo`/`redo`。回归测试：`versioned_undo_redo_integration`、`versioned_checkpoint_undo`。

## P2 — 能力缺失/文档勘误

- **CLI 默认模型修正**：`fd-cli` 全部子命令默认模型 `qwen3.5`（小写，gateway 404）→ `Qwen3.5-9B-4bit`（gateway 实测可路由）。
- **fd-cli 测试补齐**：原 0 测试，新增 5 个 CLI 参数解析测试。
- **设计规范预设文档勘误**：`CLAUDE.md`「3 presets」→「2 built-in presets（Apple HIG / minimalist admin），robot-sim 规划中」对齐代码实际。
- **反向同步边界**：codegen 正向生成不变；反向已有 `parse-html`（HTML → PenDocument）路径，CLI `parse-html` 子命令可用，作为代码改回设计的双向兜底。

## 多模态负载验证

- 单测 `chat_with_image_sends_data_url`：验证请求体含 `data:image/png;base64,` + `image_url`。
- 单测 `image_to_ui_async_sends_real_image`：验证 `image_to_ui_async` 走真实图片负载（非仅文字描述）。

## 上游问题（非本仓缺陷，已定位）

- fusion-mlx 视觉模型 `mlx-community--Qwen2.5-VL-7B-Instruct-4bit` 推理报 `RuntimeError: There is no Stream(gpu, 0) in current thread`（GPU stream 与多模型并发加载冲突），导致真实 VL 推理 502。本仓多模态负载结构已验证正确，待上游修复后即可跑通。
