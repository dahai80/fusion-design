## 背景

Issue #30（Config Phase 3 legacy key 名治理）：`FUSION_MLX_API_KEY` 为迁移期 legacy 名，规范名 `FUSION_CLIENT_KEY`（config-conventions §4 别名链：规范名 → legacy 兜底 → 未设 WARN）。Phase 3 于 2027-01-01 将 legacy 名 warn 升级为 error 并删除别名链。本仓验收标准：check-env 对 fusion-design 报 0 条 `[legacy]` WARN（此前 1 条，`Scripts/build.sh` 注释行）。

仅改 help 文案会让文档与代码行为矛盾（代码 9+ 处读 legacy 名）。故按别名链端到端修复：代码先读规范名、legacy 兜底并 WARN，文档/help 全面切规范名。
