# v0.1.25

## Summary

Issue #35 closure: unified AI DTO contract + minimum viable canvas UX in the workbench.

## Changes

### Unified API contract (issue #35, P2-1)

- **Contract doc**: new `docs/API.md` — request/response schema for every endpoint (required vs optional fields), error-shape table, contract-test pointers.
- **Field-located 4xx errors**: every 4xx validation failure now returns `{"error", "field"}` — `field` names the missing/wrong input (`prompt`, `instruction`, `image_base64`, `region`, `format`, `session`, `version`, `ds`, `body` for unparseable JSON). No more reverse-engineering which field failed.
- **`tokens` endpoint**: implemented and GET-only (`GET /api/tokens?ds=&theme=`); wrong-method requests get 405 with a `hint` pointing to the correct call (`method_not_allowed` also hints GET for other read-only endpoints: health/design-systems/sessions/artifacts).
- **Contract test suite**: `handlers::contract_tests` pins 4xx field-location across generate/iterate/rollback/restore/export/tokens/session_info, success shapes for rollback/export/session_info/version_doc/tokens; `router::tests::method_not_allowed_contract` pins the 405 shape.

### Minimum canvas UX (issue #35, P2-2, phased item)

- **Layer list** (right column): every node as `kind` + `name`; click selects.
- **Node selection**: click in the layer list sends `node.select` to the wasm bridge (existing highlight on `data-node-id` elements); clicks on the canvas come back as `node.click`/`node.select` bridge events — previously discarded, now consumed and mirrored onto the layer list (no echo loop).
- **Undo/Redo** (canvas header): steps the version stack pointer via `rollback` (pointer move, no new version); disabled states at stack edges.
- Scope kept honest: core canvas interactions only, not a full editor — phased item.

## Verification
