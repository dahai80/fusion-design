## 商用加固（5 个非阻塞项落地）

为"商用万无一失"追加 5 项加固：

1. **cargo-audit CI 门禁**（`.github/workflows/ci.yml` 新增 `audit` job）：
   `cargo install cargo-audit` + `cargo audit` 扫描依赖已知漏洞。`continue-on-error: true`
   作早期预警，不阻断主流程。
2. **release-pack CI 鲁棒性**：触发条件由 `github.ref == main` 改为 `startsWith(github.ref, 'refs/tags/v')`
   + `continue-on-error: true`。macos-14 runner 供给瓶颈不再阻塞 main CI 恒绿；tag 推送时尽力出包。
   同时为 `on.push` 增加 `tags: ["v*"]` 触发。
3. **deny-panic CI 门禁**（新增 `deny-panic` job）：grep 校验 `crates/*/src/*.rs` 生产代码
   顶层 `panic!`/`unimplemented!`/`todo!`/`unreachable!` 语句数为 0（排除 tests 与 `=>` match 臂断言）。
   基线 0，任何回归将失败。
4. **生产 unwrap 加固**（`fd-canvas-core`）：`compute_flex_layout` / `compute_grid_layout`
   中 6 处 `taffy_tree.new_leaf/new_with_children/layout().unwrap()` 替换为 `match` + `tracing::warn!`
   + 回退自由布局（复用既有 `compute_node_layout` fallback 路径）。生产 unwrap 清零，无静默 panic。
5. **fd-design-lint 对齐 op-design-lint**：确认 `fd-design-lint` 已是 op-design-lint 的自建替身——
   13 条规则（ContrastCheck / UnlabeledInput / TextEffects / AbnormalRotation / EmptyEffects /
   TokenInconsistency / UnnamedNode / TextOverflow / OverlappingNodes / HardcodedSpacing /
   HardcodedFontSize / MissingInteractionState / LayoutInconsistency）+ auto-fix。
   op-design-lint 从未 vendored（同依赖私有 jian-ops-schema），fd-design-lint 已覆盖核心 lint 需求。

## CI 落地修复（PR #15 推送后两轮修复）

首次推送 PR #15 后，`build-test` job 即绿，但两个加固 job 报错，按
"遇到报错的用例都要定位修复"原则逐一修复，最终 CI 三 job 全绿：

1. **deny-panic pipefail 误杀**（CI 脚本 bug，非代码回归）：grep 零匹配时
   返回非零退出码，`set -euo pipefail` 在 `echo` 前提前退出（exit 1），
   导致"零 panic"这一正确状态被判失败。修复：管道末尾追加 `|| true` 兜底，
   零匹配能正常走到 `echo` 与 `if` 判断。本地复现 `生产代码顶层 panic 语句数: 0` → PASS。
2. **lopdf RUSTSEC-2026-0187 栈溢出漏洞**（hardening item #1 audit job 暴露）：
   `lopdf 0.35.0` 经 `printpdf 0.8.2` 引入，深层嵌套 PDF 对象栈溢出
   （severity 7.5 high）。`cargo update` 无法在 0.8.x 内升 lopdf，
   故升级 `printpdf 0.8 → 0.12.5`（其 lopdf 0.44.0 已修复，需 >=0.42.0）。
   - 关闭 printpdf 默认 `html` feature，避免拉入 azul-layout/svg2pdf 重依赖
     （仅用 `ops::Op` 内置字体 API）。
   - API 迁移：`SetFontSizeBuiltinFont`/`WriteTextBuiltinFont` →
     `SetFont{PdfFontHandle::Builtin}`/`ShowText`（0.12 重命名）。
   - `render_pdf` 签名与输出 PDF 内容不变；fd-export 25 测试全绿。
   - 另有 9 条 unmaintained/unsound 警告（fxhash/instant/kuchiki/paste/
     proc-macro-error/rustybuzz/ttf-parser/rand 0.7.3）为上游传递依赖，
     cargo-audit 报为 warning 非 vulnerability，不阻断（audit job 已 success）。

CI 最终状态（run 31239351543）：`fmt+clippy+test+wasm` success、
`cargo-audit` success、`deny-panic` success、`release-pack` skipped（tag 触发，符合预期）。
PR #15 squash-merge 至 main（commit 754cf6d）。
