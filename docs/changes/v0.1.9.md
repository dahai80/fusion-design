# v0.1.9 — Roadmap 落地：robot-sim 预设 + 自建 MCP 协议层 + op-* 深度集成

> 日期：2026-08-07
> 上版：v0.1.8（CI 全绿 / 360 tests）
> 本版：v0.1.9（369 tests / 0 failed / 1 ignored）

## 背景

PRD 模块 3「本地设计系统与组件库」第三套内置规范（机器人仿真控制台）此前标注为
"planned but not yet registered"；PRD 模块 6「生态联动能力」的 MCP 协议原计划依赖
上游 `op-mcp`，但其依赖私有 `jian-ops-schema` 无法引入；`op-editor-core` / `op-codegen`
同理。本版按用户裁定的「自建替身（推荐）」路径一次性落地三项路线图。

## 变更清单

### 1. robot-sim 设计预设（fd-design-system）

- 新增 `builtin_robot_sim()` — 机器人仿真控制台设计规范：
  - 14 个 Token：深色工程背景（`#0F1115`）、面板表面、高对比前景、次要文本、
    蓝/绿/黄/红 语义色（accent/success/warning/danger）、正文字号、等宽数据字号、
    等宽字体族、面板圆角、仪表间距基准、面板阴影。
  - `dark_tokens`：8 个夜间深度变体（极深背景 `#010409` 等）。
- `register_builtin()` 注册第三套规范，模块 doc 与 `register_builtin` 注释更新为"三套"。
- `fd-cli list-design-systems` 现输出三个预设（验证通过）。
- 测试：`register_builtin_loads_two` → `register_builtin_loads_three`（断言 len==3），
  新增 `robot_sim_preset_registered_and_lookup`（校验 color.bg / color.danger / font.mono）。

### 2. fd-ecosystem 自建 MCP 协议层（替代 op-mcp）

- 新增 JSON-RPC 2.0 over stdio 的 MCP 服务端，100% 本地、无公网：
  - `McpRequest` / `McpResponse` / `McpError`（标准 JSON-RPC 错误码 -32700/-32601/-32602/-32603）。
  - `McpTool` trait + `McpServer`（`initialize` / `tools/list` / `tools/call` 分派，
    `handle_line` 处理单行文本）。
  - 3 个内置工具（桥接 EcosystemLink 既有能力）：
    - `list_targets` — 列出生态联动目标目录。
    - `search_templates` — 检索 Fusion-KB 设计模板。
    - `send_message` — 发送联动 IPC 消息并落盘。
  - `McpServer::register_builtin_tools(link)` 一键注册。
- 模块 doc 更新：文件 IPC + 自建 MCP 互补定位。
- `Cargo.toml` 注释更新：`op-mcp` 已由自建层替代。
- 7 个新测试：initialize / tools/list / 未知方法 / 解析错误 / list_targets / search_templates /
  send_message 落盘 / 未知工具。fd-ecosystem 测试 20 → 27。

### 3. op-editor-core / op-codegen / op-mcp 深度集成（自建替身确认）

- `op-editor-core` → `fd-canvas-core`（PenDocument/PenNode 数据模型，已存在且可用）。
- `op-codegen` → `fd-codegen`（HTML / React+Tailwind 生成，已存在且可用）。
- `op-mcp` → `fd-ecosystem` 自建 MCP 层（本版落地）。
- 工作区 `Cargo.toml` 注释：将原 commented-out dep 行改为替身映射说明。
- `op-design-lint` 暂未替身（已有 `fd-design-lint`，按需后续对齐）。
