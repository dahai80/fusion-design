# 变更说明 v0.1.3（补丁）

本补丁处理 issue #5-#10，不引入破坏性变更。所有修改遵循 100% 离线约束（唯一 HTTP 流量指向 `127.0.0.1` fusion-mlx）。

## #6 [P0] fusion-mlx 鉴权头缺失（fd-ai-adapter）

**现象**：fusion-mlx 启用 RouteGuard + API-key 双鉴权后，fd-ai-adapter 的 5 个出站请求点均缺少必要鉴权头，全部 403/401。

**修复**：在 fd-ai-adapter 所有出站请求点补齐：
- `X-Fusion-Route: fusion-design`（RouteGuard 校验，403）
- `Authorization: Bearer ${FUSION_MLX_API_KEY}`（API-key 校验，401）
- 新增 `FUSION_MLX_BASE_URL` 环境变量覆盖（默认 `http://127.0.0.1:11434`，注意非 11432）。

**验证**：62 个 fd-ai-adapter 测试通过；E2E 真实模型推理链路打通。

**涉及文件**：`crates/fd-ai-adapter/src/lib.rs`

## #7 [E2E] codegen 丢弃嵌套子节点（fd-codegen）

**现象**：codegen 仅对 `NodeKind::Group` 递归渲染子节点；而 parse-html 将带子节点的容器 `<div>` 映射为 `Rect`（非 Group），导致子节点被静默丢弃，HTML->PenDocument->code 往返丢结构。

**修复**：`node_to_html` / `node_to_react` / `node_to_swiftui` 对所有 node kind 统一收集并注入子节点：
- Rect/Circle：div 内联 children
- Text：children 追加到文本后
- Image：有 children 时包裹 div
- SwiftUI：非 Group 节点有 children 时用 ZStack 包裹

**验证**：新增 3 测试（HTML/React/SwiftUI 嵌套渲染），fd-codegen 共 20 测试通过。

**涉及文件**：`crates/fd-codegen/src/lib.rs`

## #8 [E2E] PNG 导出 Token 颜色回退黑色（fd-export）

**现象**：usvg 无法解析 CSS Custom Property `var(--color-*)`，PNG 光栅化时 fill 回退为黑色。

**修复**：导出前经 `DesignSystemRegistry` 将 token 引用解析为 hex 色值：
- 新增非破坏性方法 `Exporter::from_pen_document_with_tokens(doc, fmt, out, &reg)`
- `resolve_color_var` 兼容三种形式：`var(--color.accent)`（dot）、`var(--color-accent)`（dash）、`token:color.accent`
- fd-cli `export` / `export-batch` 命令切换到带解析路径，并激活文档声明的 `active_design_system`

**验证**：新增 6 测试；CLI E2E 导出 SVG 含 `#007AFF`、无 `var(--` 残留；PNG 像素采样 `(0,122,255,255)` 非 black fallback。fd-export 共 25 测试通过。

**涉及文件**：`crates/fd-export/src/lib.rs`、`crates/fd-export/Cargo.toml`、`crates/fd-cli/src/main.rs`
