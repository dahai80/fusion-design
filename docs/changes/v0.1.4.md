# 变更说明 v0.1.4（补丁）

修复 `fd-host-web`（WASM 渲染层）内存泄漏与执行卡死。详见 `fix-host-web-leak-hang.md`。

## 修复

- **P0-1** 容器级监听器每次 `render_dom` 重复注册 + `forget` 累积 → 同一事件被 N 个累积 handler 处理 → 帧率塌陷卡死。修复：`LISTENERS_INSTALLED` AtomicBool 幂等，仅首次注册 6 个 `setup_*`。
- **P0-2** 拖拽 mouseup/mousemove 泄漏 + 重复触发 → 第 K 次拖拽时 K 组历史 mouseup 同时响应 → 位置错乱卡死。修复：4 处 `on_up` 改 `Closure::once`，触发后自清理。
- **P0-3** `schedule_raf` 标志位竞态致渲染永久停摆 → rAF 注册失败/回调 panic 时标志永久卡 true → 画面冻结。修复：注册失败与回调内先复位标志，内存序提升 SeqCst。
- **P1-1** SHELL 锁中毒即全死。修复：`shell_lock()` 用 `into_inner()` 容错，替换 3 处 `unwrap`。
- **P1-2** `render_page` 持锁期间全量重绘阻塞消息。修复：仅持锁取 `canvas_id` 后释放，无锁重绘。
- **P2-1** 递归渲染无深度上限致栈溢出。修复：`MAX_RENDER_DEPTH=64`，两函数加 `depth` 参数 + 超限警告。
