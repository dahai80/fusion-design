# v0.1.30

## Summary

CI retrofit closure (issue #45) and RustSec advisory cleanup: CI concurrency cancellation + docs-only path filtering on the PR lane, plus dependency bumps that clear 7 new RustSec advisories with zero `audit.toml` ignores.

## Changes

- **CI concurrency + cancel-in-progress** (#45, PR #46): `concurrency: {group: ${{ github.workflow }}-${{ github.ref}}, cancel-in-progress: true}` on `ci.yml` and `docs.yml` — superseded pushes cancel stale runs instead of queueing.
- **Docs-only PR path filter** (#45, PR #46): `paths-ignore: ["**.md"]` on the `ci.yml` `pull_request` trigger — docs-only changes no longer burn the full Rust gate (docs validation stays on `docs.yml`).
- **Checklist disposition** (#45, documented in PR #46): Swatinem/rust-cache already present on build-test/build-test-macos/release-pack; test sharding and tiered gates assessed and **not** adopted — the suite (574 tests) runs in ~5 s, wall time is dominated by toolchain/dependency installation, and per-PR CI is kept authoritative rather than replaced by batched runs. Recorded push-to-main run times: 2m17s / 3m41s / 7m07s; tag runs (incl. release tarball): 10m18s / 12m14s / 28m14s.
- **RustSec cleanup** (PR #47): targeted lock bumps tokio 1.54.1 (RUSTSEC-2026-0386), rustix 1.1.6 (RUSTSEC-2026-0486), quinn-udp 0.5.16 (RUSTSEC-2026-0538), chacha20 0.10.2 (yanked) + ecosystem bumps resvg 0.45→0.50 (drops unmaintained rustybuzz/ttf-parser) and scraper 0.22→0.29 (drops unmaintained fxhash). No code changes; zero audit.toml ignores.
- **Docs**: `docs/DATASETS.md` YAML frontmatter (required by the docs validator).

## Verification

- PR #47 full CI green: cargo-audit (blocking) pass, fmt/clippy/test/wasm pass, check+test macos pass, deny×3 pass, validate pass.
- `cargo check --offline` after the version bump updates only workspace version lines in `Cargo.lock` (no generate-lockfile drift).
