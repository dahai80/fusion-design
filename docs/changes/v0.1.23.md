Release date: 2026-11-02

## Bug 1：健康徽章显示 embedding 模型且不可改

工作台徽章显示 `MLX ✓ BAAI--bge-m3`——`health_check` 取 `/v1/models` 列表**首个**
条目，而 MLX 服务器恰好先加载了 bge-m3（embedding 模型）。显示的不是
generate 实际用的模型，也没有任何切换入口。

**Fix**

- `/api/health?deep=1` 新增 `chat_model` 字段（`resolve_model` 链：请求显式 >
  `FUSION_MLX_MODEL` > 内置缺省 Qwen3.5-4B）。
- 工作台工具栏新增模型下拉：只列**对话模型**（家族白名单 qwen/llama/glm/
  deepseek/jais/nemotron/kimi/minimax/vibe − 模态黑名单 image/vl/ocr/tts/
  embed/flux/video/…），缺省选中 `chat_model`，选择持久化 `fd-model`
  并随 generate/iterate 请求下发（`model` 字段，后端本就支持）。
- 徽章只表示可用性（`MLX ✓` / `MLX 不可用`），不再显示误导性模型名。
- 截图还原仍走视觉模型缺省（Qwen2.5-VL），不随下拉变化（视觉任务需要 VL）。

实测（gateway /v1/models 返回 46 项）：过滤后下拉为 20 个对话模型，
缺省 `mlx-community--Qwen3.5-4B-MLX-4bit`。

## Bug 2：未遵守 shell 统一主题/语言标准

落地页/工作台右上角自带「中文/English」下拉与主题切换按钮，主题/语言键
（`fd-lang`/`fd-theme`）也与 shell 约定不一致——违反 spec §2.1
「Shell 管外壳，模块不实现、不复刻」。

**Fix**

- 删除两个页面的语言下拉与主题切换按钮（用户建议采纳）。
- 新增共享 `shell-sync.js`：same-origin iframe 读外壳 `html.light` 与
  `documentElement.lang`，监听外壳 class/lang 属性变化与 `fusion:theme` /
  `fusion:lang` 事件；独立打开时回退 shell 约定键 `fusion.shell.theme` /
  `fusion.shell.lang`（默认 dark / zh）。三个页面（落地页/工作台/查看器）统一接入。
- 外壳切主题时工作台画布即时重渲染（保持既有行为）。
