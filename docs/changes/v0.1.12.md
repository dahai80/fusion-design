## 背景

对抗审计（0827）裁定 v0.1.12 baseline **不可企业级生产商用发布**，新发现 53 项缺陷：架构硬伤 11（A-1..A-11）+ 运行时风险 17（R-1..R-17）+ 工程实现缺陷 25（E-1..E-25）。v0.1.10/v0.1.11 为中间迭代（changelog 缺口，未回溯杜撰）。PR #21 按优先级闭合 P0-P2 全量 + P3 部分（A-2/A-3/A-5 落地，**A-4/A-7/E-18 三项 P3 延后**，见下「留待后续」）+ M-5 重试退避 + 文档同步补丁。product-0827 §11 终判：50/53 闭合 + 3 项 P3 可接受延后 → 具备企业级商用技术底座。

## 变更清单

### Phase 0 — 门禁盲区与 TLS 离线依赖

- **E-1** `deny-external-http.sh` / `deny-unwrap-expect.sh`：补嵌套 `src/**/*.rs` glob，对齐 `deny-panic.sh` 已修模式，闭合嵌套目录扫描盲区。
- **E-5** `Cargo.toml`：`reqwest` 切 `default-features=false` + `rustls-tls`，纯 Rust TLS 后端消除 `openssl-sys` 系统依赖，离线约束下规避 macOS/Linux OpenSSL 差异。
- **E-4** `unwrap-expect-allowlist.txt`：删 6 条 fd-host-web 死条目，加逆向校验提示死条目积累。

### Phase 1 — 安全 sink（阻断商用 P0）

- **E-2** `fd-ai-adapter is_private_or_local`：删 `0.0.0.0`/`[::]` unspecified 放行，拒绝绑定全接口。
- **R-5** `fd-export` SVG `<image>` href：新增 `sanitize_image_url`，拒 `javascript:`/`data:text/html`/`http(s):`，仅放行 `data:image/*` + 相对路径。
- **R-6** `fd-codegen` SwiftUI 注入：新增 `escape_swift_string`，转义 `\` `"` `\n` `\r`，fill/stroke/font_family 原样塞入处经转义包裹。
- **R-2** `fd-ai-adapter parse_ui_json`：修复失败改 `bail!` 替代 `synthesize_fallback_doc` 伪成功占位，fail visibly。

### Phase 2 — 运行时正确性

- **R-3** `chat_async`/`chat_with_image`：抽 `retry_async` 通用异步重试，对齐 `blocking_post` 指数退避。
- **R-4** `chat_stream_messages`/`check_generate`：建连循环加 `FUSION_MLX_RETRY_DEADLINE_SECS` 总 deadline。
- **R-12** SSE buffer：移除 `!buffer.contains(b'\n')` 绕过条件，超 8MB 即 bail；增量 `last_newline_idx` 消除全扫。
- **R-13** `encode_image_base64`：改 `tokio::fs::read` async，不阻塞 runtime。
- **R-14** `fd-cli health` 子命令：`available:false` 改非零退出码，破假绿。
- **R-7** `fd-ecosystem consume`：rename 抢占 `.processing/` 子目录，跨进程原子防丢消息。
- **R-8** `fd-ecosystem list`：扩展名过滤仅 `.json`，拒代码产物污染。
- **R-9** `sanitize_ipc_subpath`：退化分支拒符号链接。
- **R-10** `fd-export` PDF CJK：运行时检测系统 PingFang 字体，存在则内嵌，否则 warn 回退。
- **R-11** PDF 静默跳过：聚合 `skipped_kinds` 清单显式打印。
- **R-15** `fd-host-web shell_lock`：中毒 Mutex 重置 None 而非取脏数据，拆短锁。
- **R-16** rAF 嵌套/panic 停摆：抽 `schedule_viewport_update`，`catch_unwind` 包回调复位 `RAF_SCHEDULED`。
- **R-17** Shift 多选：`WebShellInner` 加 `selected_ids: HashSet`，`toggle` 增删同步。
- **A-1** 多节点 failover：`FusionMlxClient` 加 `endpoints: Vec<String>`，`FUSION_MLX_BASE_URL` 逗号分隔多值，503/502 切下一节点。
- **A-11** canvas/DOM 双轨：`render_page` 清空 DOM 容器 + selected，`WebShellInner` 加 `render_mode` 字段。

- **A-4** 库 crate anyhow 泄漏：**延后**（见「留待后续」）。发版时 `fd-canvas-core` `from_json`/`validate_limits` 仍返 `anyhow::Result`，公共 API 强类型化未做。

## 留待后续（3 项 P3 延后，非本版闭合）

0827 审计将 A-4/A-7/E-18 列为 P3「3 个月内必须启动」（audit line 484）。本版（bffa237）未闭合，据实记录：

- **A-4** 库 crate anyhow 泄漏公共 API：发版时 `fd-canvas-core` `from_json`/`validate_limits`/`migrate_schema` 仍返 `anyhow::Result`，下游无法按变体 downcast。→ 后续 commit `d59149d`（v0.1.14 分支 ARCH-13）改 `fd-canvas-core` 三者返 `Result<_, CanvasError>`（单 crate）；`fd-export`/`fd-codegen`/`fd-design-lint` 其余库 crate 公共 API 仍返 `anyhow::Result`，强类型化待后续做。
- **A-7** schema 迁移框架：发版时无 `migrate_schema`。→ 后续 commit `bb2c7a2`（ARCH-5 audit backfill）落地 `migrate_schema` 框架（v1 空迁移，v2 破坏性变更时加分支）。
- **E-18** `UndoRedoStack` delta/COW：发版时仍 `VecDeque<PenDocument>` 全量快照（max depth 50）。product-0827 FUNC-7 裁定 **accepted-degradation**——有意设计，MVP 小文档可接受，非缺陷，无 TODO 标记。delta/COW 未做，后续超大文档场景如成缺口再演进。
