# v0.1.18 (2026-11-02)

Patch release: web workbench (fd-server) + ecosystem exits. Issues #31, #33 (in-repo side), #32 (in-repo side). All changes 100% offline — inbound HTTP on 127.0.0.1 only.

## New: fd-server web workbench (issue #31, frame D1 + DS-0)

- **Crate**: `fd-server` — hyper 1.x (http1, inbound-only) on `127.0.0.1:11493` (port-registry owner `fusion-design`). New crate #14 in the workspace.
- **APIs**:
  - `GET /api/health?deep=1` — async deep probe (gateway + model + auth). Note: the sync blocking client must never be called inside an async handler (deadlock — internal runtime inside tokio).
  - `POST /api/generate` / `POST /api/iterate` — chat-driven design with a 2-attempt retry loop that varies the prompt (the gateway caches identical prompt+model responses, so retries MUST vary the string) and a model-JSON repair chain.
  - `POST /api/restore` — screenshot → local vision model (`mlx-community--Qwen2.5-VL-7B-Instruct-4bit` default) → editable PenDocument. Vision payload sends `temperature: 0.6` (temperature=0 makes 4-bit VL models deterministically degenerate).
  - `POST /api/export` — HTML / React+Tailwind download.
  - `POST /api/rollback`, `GET /api/version/{session}/{n}`, `GET /api/sessions` — version history.
- **Workbench UI**: compile-embedded three-pane page (chat / canvas / versions) with zh-en i18n, light/dark themes, paste-to-restore, serving the real fd-host-web WASM canvas (runtime discovery: `FUSION_DESIGN_WASM_DIR` > exe dir > cwd > target wasm dirs; missing assets fail visibly with generation instructions).
- **Lifecycle**: `start.sh` (start/stop/status/log, PID file, graceful kill); release tarball now ships `fusion-design-server`.

## New: ecosystem exits (issue #33, DS-2)

- `POST /api/send-to-code` — resolves the session doc (current or pinned version), writes HTML + React/Tailwind exports plus a notification into the fusion-code IPC directory via `fd_ecosystem::EcosystemLink::sync_to_code`. Returns the written file list.
- `POST /api/save-artifact` — writes a `save_artifact` IPC message into the fusion-artifacts-engine directory with `source: "fusion-design"` provenance, full document payload, title, and version.
- Workbench export panel gains **[发给 Code]** / **[存 Artifacts]** buttons (guarded on session existence, chat feedback, zh/en labels).
- IPC base: `FUSION_DESIGN_DATA_DIR` > `~/.fusion-design`.
- Cross-repo consumers (file-IPC contract frozen producer-side): fusion-code#228, fusion-artifacts-engine#76.

## Hardening: model-JSON repair chain (fd-skills)

Real 4-bit VL outputs exhibited a defect zoo: missing element `{`, stray quotes, duplicate numbers, garbage runs, orphan key strings, trailing commas, multiline missing commas. Fixes, each with a regression test:

- Repair order is load-bearing: double-colon → brace dedupe → missing-comma scan (all whitespace) → `fix_value_garbage` → `fix_element_open_brace` → `balance_json_braces`. Value garbage must be fixed before the structural scan; element braces before balancing.
- `fix_value_garbage`: stack-tracked scan, five targeted rules (orphan key string, value-end stray quote, quote-before-structure, duplicate number — only after whitespace to avoid eating in-token digits, garbage run after closed string).
- `fix_element_open_brace`: missing array-element `{` insertion + trailing comma removal; pop compares the counterpart opener.
- `salvage_pen_document`: final fallback — parses top-level node objects individually, keeps valid nodes, drops corrupt ones (restoration-draft semantics).
- System prompt now demands single-line compact JSON.
