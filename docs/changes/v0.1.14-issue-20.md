# v0.1.14 — issue #20：fd-cli chat 新增 SSE 流式模式，统一 studio sendDesignChat 路径

> 日期：2026-08-30
> 分支：feat/issue-20-chat-sse-mode
> 关联 issue：#20（feat: expose chat --stream subcommand in fd-cli to unify fusion-studio sendDesignChat path）
> 上游跨工程 issue：fusion-studio#205

## 背景

issue #20 前提核实：fusion-studio `DesignBridge.sendDesignChat`（DesignBridge.swift:1196）
**实为内联 URLSession HTTP**——自管 Bearer 鉴权 + 自管 SSE 解析 + 自管 `X-Fusion-Route` header。
这重复实现了 `fd-ai-adapter` 已有的保护逻辑：RouteGuard / `validate_localhost` / Bearer /
M-5 重试 / false-green 破除（`check_generate`）。

> 旧文档（chat.rs / main.rs / common.rs 注释）称「studio 走 gateway TCP NDJSON，不经
> fd-cli chat，无 studio 消费方」——**stale/错误**。studio 经 `sendDesignChat` 直连 MLX
> HTTP，不经 gateway TCP 亦不经 fd-cli。本 issue 闭合方向：studio 改调 fd-cli `chat`，
> 鉴权/RouteGuard/endpoint 解析统一复用 adapter，调用方不重实现。

## 格式裁决

studio 现有子进程解析器 `runFusionDesignStream`（DesignBridge.swift:775）消费 **raw OpenAI
SSE**：按 `data: ` 前缀逐行解析，取 `choices[0].delta.content` 为 token，遇 `data: [DONE]`
结束。fd-cli 既有 `chat --stream --json` 输出 **NDJSON**（每行一帧 `delta`/`chat_done`/
`error`，issue #17 契约），与 studio 解析器不兼容。

裁决（用户 2026-08-30 裁定）：**加 SSE 模式，保留 NDJSON**。
- `--format sse`：raw OpenAI text/event-stream，studio 子进程管道零改动可消费。
- `--format ndjson`（默认）：保留 issue #17 既有 CLI 管道/脚本契约，不破坏既有消费方。

## 本分支闭合清单

### fd-cli `chat` 新增 `--format` 枚举

- **`ChatStreamFormatArg` 枚举**（`crates/fd-cli/src/main.rs`）：`Ndjson` / `Sse`，clap
  `value_enum`，`--format` 默认 `ndjson`。Chat clap struct 加 `format` 字段，dispatch 传参
  至 `chat::run`。
- **`chat::run` 格式分支**（`crates/fd-cli/src/commands/chat.rs`）：`format` 参数分支
  NDJSON vs SSE 成帧。关键：**每帧 `stdout.flush()`**——子进程管道 block-buffered，不 flush
  则 studio readabilityHandler 攒块到缓冲满才收，流式体验退化。
- **SSE 成帧纯函数**（`crates/fd-cli/src/common.rs`）：`sse_frame_delta(token)` /
  `sse_frame_done()` / `sse_frame_error(msg)`，raw `data: <json>\n\n` 格式，对齐 studio
  解析器契约。
- **stale 文档重写**：chat.rs / main.rs Chat doc 注释改 issue #17 → #20 演进口径（原
  「无 studio 消费方」标注为已核实错误，改为「studio 内联 HTTP 重复实现保护逻辑，#20
  闭合方向改调本子命令」）。

### 测试

- `common::tests::sse_frame_delta_shape` / `sse_frame_done_shape` / `sse_frame_error_shape`：
  SSE 成帧契约单测（data: 前缀 / choices / [DONE] / 行数）。
- `tests::parse_chat_defaults`：补 `format` 默认 `Ndjson` 断言。
- `tests::parse_chat_format_sse`：`--format sse` 显式解析单测。

### 真模型验证

`Qwen3.8-27B-4bit`（本地已加载）直连 MLX `127.0.0.1:11434`：
- `--format sse`：输出 `data: {"choices":[{"delta":{"content":"Hi"},"index":0}]}` +
  `data: {"choices":[{"delta":{},"finish_reason":"stop","index":0}]}` + `data: [DONE]`，
  对齐 studio 解析器契约。
- `--format ndjson`：输出 `{"token":"Hi","type":"delta"}` +
  `{"finish_reason":"stop","type":"chat_done"}`，issue #17 契约不变。
