# v0.1.27

## Summary

Issue #41 + #42 closure: desigma acceptance gate in fd-design-lint, and the fd-server web workbench packaged as a standard union-web shell module.

## Changes

### Desigma acceptance gate (issue #41, `fd-design-lint` / `fd-cli` / `fd-design-system`)

- **4 new Error-severity rules**: `bare_color_literal` (raw hex/rgb/named color matching no token), `off_token_spacing` (gap/padding off the spacing token scale), `off_token_radius` (radius off the scale), `missing_dark_pair` (color token without a dark_tokens counterpart).
- **`LintProfile`** (`fd-design-lint`): `default` = all 17 rules (legacy behavior unchanged); `desigma` = the 4 gate rules. `Linter::with_profile`.
- **CLI gate semantics**: `fd-cli lint --profile desigma --gate` — exit 0 pass / 1 Error violations / 2 runtime failure; violations JSON (rule, node_id, message, suggestion) on stdout for the cowork desigma pipeline. Explicit `--rules` overrides `--profile`.
- **4th builtin preset `desigma-aligned`**: shell-brand accent `#4F7CFF`, spacing 8/16/24, radius 4/8/16, every color token ships a dark pair.
- **Mapping doc**: `docs/DESIGMA_TOKEN_MAPPING.md` — desigma `Theme` collection groups → fusion semantic tokens, gate pipeline, palette extension via `extends`/`import_json`.

### Web workbench as shell module (issue #42, `fd-server` + `web/`)

- **`POST /api/session/<id>/mutate`**: direct node patch (x/y/w/h/fill/stroke/radius/font_size/opacity) on the current version, pushes a new version (`编辑：<node_id>`) — canvas drag and token apply persist without a model round-trip. Field-located 4xx.
- **`GET /api/tokens`** now returns `tokens[{name,value}]` (dark theme = light base merged with dark overlay) for the token panel.
- **Workbench UI**: token panel (constrained picking from the active design system; click = fill, Shift+click = stroke, `radius*`/`font.size*` mapped), canvas drag persisted via debounced (300 ms) mutate, **Save .fusiondesign** (PenDocument JSON download), `?embedded=1` hides own navigation (PRD §3.3), 401 rendered inline — the module never redirects (issue #28 contract).
- **`web/manifest.json`** (repo root, PRD §5.1) + `start.sh` best-effort registration to gateway `POST /api/v1/shell/manifests`. Gateway-side hosting (`/shell/fusion-design/`) + registration endpoint = upstream request dahai80/fusion-gateway#601 (cross-repo constraint: issue, not patch).
