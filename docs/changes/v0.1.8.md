# 变更说明 v0.1.8（补丁 — CI 流水线 + train 子命令合并）

## 背景

v0.1.7 完成全部商用加固后，本补丁落地两条收尾：合并 issue-12 train 子命令分支、建立 GitHub Actions CI 流水线确保 lint/CI 长绿。无 Rust API 变更，纯补丁版本。

## 合并：issue-12 train 子命令（PR #13）

- **来源分支** `issue-12-train-subcommand`（commit `126dc3a`）合并入 main（合并 commit `9579d5d`）。
- **能力**：`fd-cli` 新增 `train` 子命令，集成 fusion-trainer 提供设计语料微调。
  - 参数：`--dataset`、`--model`、`--method`（默认 `sft`，可选 `rlsl`）、`--config`。
  - 实现：shell out 调用 fusion-trainer CLI，经 `fd-ecosystem::TrainerClient::run_sft` / `run_rlsl`。
  - 无 endpoint 字段（训练不经推理网关）。
- **冲突解决**：`fd-cli/src/main.rs` 保留 HEAD 的测试模块；`fd-ecosystem/src/lib.rs` 保留 HEAD 的 rustfmt 多行格式；修复自动合并遗留的重复 `}`（948-949 行）。
- **关联**：issue #12（closed）、PR #13（merged）。

## CI 流水线（`.github/workflows/ci.yml`）

镜像本地门禁，确保 push/PR 到 main 自动校验 lint 与测试全绿：

- **`build-test` job（ubuntu-latest）**：
  - 工具链 `1.94` + `wasm32-unknown-unknown` target（对齐 `rust-toolchain.toml`）。
  - `cargo fmt --all --check` → `cargo clippy --workspace --all-targets -- -D warnings` → `cargo check --workspace` → `cargo test --workspace` → `cargo build -p fd-host-web --target wasm32-unknown-unknown`。
  - `Swatinem/rust-cache@v2` 缓存 target。
- **`release-pack` job（macos-14，仅 main）**：
  - `build-test` 通过后运行 `./Scripts/build.sh` 产出 Apple Silicon release tarball。
  - `actions/upload-artifact@v4` 上传 `dist/*.tar.gz` 为 artifact。
- **安全**：所有 `run:` 均为静态 cargo/脚本命令，无 issue 标题/PR body/commit message 插值，无注入面。
